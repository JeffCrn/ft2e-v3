# 13 · Glossaire BET

Vocabulaire de référence pour rédiger juste et faire les bons choix éditoriaux. Cette liste sert tant à Claude Code (terminologie correcte dans le code et les commentaires) qu'aux rédacteurs (graphie exacte sur le site).

## Acteurs du bâtiment

| Terme | Définition courte |
|---|---|
| **MOA** (Maître d'OuvrAge) | Le client final, celui qui commande et finance le projet. Peut être public (commune, OPH, port) ou privé (promoteur, particulier). |
| **MOE** (Maître d'ŒuvrE) | Celui qui conçoit et coordonne. Souvent l'architecte mandataire + ses BET cotraitants. |
| **BET** (Bureau d'Études Techniques) | Spécialiste d'un ou plusieurs lots techniques. FT2E est un BET pluridisciplinaire. |
| **OPC** (Ordonnancement, Pilotage, Coordination) | Mission de coordination chantier, souvent confiée à un cabinet dédié. |
| **AMO** (Assistance à Maîtrise d'Ouvrage) | Conseil du MOA, en amont et pendant le projet. |
| **EXE** (Études d'EXEcution) | Études techniques fines réalisées par les entreprises ou un BET dédié, après le DCE, sur la base des plans de la MOE. |
| **VISA** | Validation par la MOE des études EXE produites par les entreprises. |
| **DCE** (Dossier de Consultation des Entreprises) | Dossier transmis aux entreprises pour qu'elles chiffrent. |
| **DOE** (Dossier des Ouvrages Exécutés) | Dossier remis au MOA à la livraison, décrivant l'ouvrage tel que construit. |

## Phases d'un projet

1. **ESQ** — Esquisse
2. **APS** — Avant-Projet Sommaire
3. **APD** — Avant-Projet Définitif
4. **PRO** — Projet (études PRO)
5. **DCE** — Dossier de Consultation des Entreprises
6. **ACT** — Assistance Contrats de Travaux
7. **VISA** — Visa des études d'exécution
8. **DET** — Direction de l'Exécution des Travaux
9. **AOR** — Assistance Opérations de Réception
10. **DOE** — Dossier des Ouvrages Exécutés

## Lots techniques

| Lot | Périmètre |
|---|---|
| **CVC** (Chauffage, Ventilation, Climatisation) | Production de chaud/froid, distribution, traitement d'air. |
| **Plomberie sanitaire** | Réseaux d'eau froide, eau chaude sanitaire, évacuations. |
| **CFO** (Courants Forts) | Distribution électrique (HTA, BT), éclairage, prises de courant. |
| **CFA** (Courants Faibles) | VDI, contrôle d'accès, vidéosurveillance, sonorisation, GTB/GTC. |
| **SSI** (Sécurité Incendie) | Désenfumage, détection incendie, alarme, compartimentage. Coordination SSI = mission spécifique. |
| **GTB / GTC** | Gestion Technique du Bâtiment / Centralisée. Pilotage automatisé des équipements. |
| **VRD** | Voirie et Réseaux Divers (non couvert par FT2E). |
| **Structure** | Ingénierie structure (non couvert par FT2E). |

## Réglementations & labels

| Sigle | Détail |
|---|---|
| **RT2012** | Réglementation Thermique 2012, applicable jusqu'à fin 2021 sur le neuf. |
| **RE2020** | Réglementation Environnementale 2020, succède à RT2012. Inclut performance énergétique + ACV (analyse cycle de vie). |
| **STD** | Simulation Thermique Dynamique. Modélisation horaire du comportement énergétique. |
| **ACV** | Analyse de Cycle de Vie. Quantifie l'impact carbone du bâtiment de la conception à la fin de vie. |
| **Bbio** | Besoin bioclimatique conventionnel (indicateur RE2020). |
| **Cep** | Consommation d'énergie primaire (indicateur RE2020). |
| **DH** | Degré-Heure d'inconfort estival (indicateur RE2020 confort été). |
| **Effinergie+** | Label de performance énergétique au-delà de la réglementation. |
| **NF Habitat HQE** | Certification française qualité environnementale. |
| **BREEAM** | Référentiel international d'évaluation environnementale (origine UK). |
| **HQE** | Haute Qualité Environnementale. |
| **PAC** | Pompe À Chaleur (aérothermique, géothermique, eau/eau, etc.). |
| **VMC** | Ventilation Mécanique Contrôlée (simple flux, double flux). |
| **RGE** | Reconnu Garant de l'Environnement (qualification pour le marché de la rénovation énergétique). |
| **DPE** | Diagnostic de Performance Énergétique (obligatoire à la vente / location). |
| **Décret tertiaire** (Éco Énergie Tertiaire) | Obligation de réduction des consommations pour bâtiments tertiaires > 1000 m². |
| **NF C 15-100** | Norme française des installations électriques basse tension. |

## BIM et outils numériques

| Terme | Définition |
|---|---|
| **BIM** (Building Information Modeling) | Modélisation des données du bâtiment. Maquette numérique fédérée. |
| **Revit** | Logiciel BIM (Autodesk), standard de fait pour la MEP. |
| **MEP** (Mechanical, Electrical, Plumbing) | Lots techniques en BIM. |
| **IFC** (Industry Foundation Classes) | Format ouvert d'échange BIM. |
| **LOD** (Level Of Development) | Niveau de précision d'un objet BIM (LOD 100 → LOD 500). |
| **Clash detection** | Détection automatique des conflits entre maquettes (clashs MEP / structure). |

## Énergies renouvelables

| Terme | Définition |
|---|---|
| **PV** | Photovoltaïque. |
| **Solaire thermique** | Capteurs solaires produisant de l'eau chaude. |
| **Géothermie** | Énergie issue du sous-sol, captée par sondes verticales ou horizontales. |
| **Aérothermie** | PAC air/eau ou air/air. |
| **Réseau de chaleur** | Distribution centralisée de chaleur. |
| **Biomasse** | Combustion bois ou granulés. |
| **Récupération de chaleur** | Sur air vicié (VMC double flux), sur eaux grises, sur process. |

|---|---|

| **CCAP / CCTP** | Cahier des Clauses Administratives / Techniques Particulières. |

## Convention de graphie pour le site

- Acronymes en **majuscules sans points** : `BIM`, `SSI`, `CVC` (pas `B.I.M.`).
- Réglementations **collées** : `RT2012`, `RE2020` (pas `RT 2012`).
- Unités : `m²` (avec exposant Unicode), `°C`, `kWh/m²/an`.
- Première occurrence d'un acronyme dans une page = forme longue (acronyme).

## Droits image — règle interne

Toute photo de chantier ou de projet livré utilisée sur le site nécessite :
1. **Accord écrit** du photographe (souvent FT2E elle-même).
2. **Accord du MOA** si le projet est privé.
3. **Crédit visible** si exigé contractuellement.

Un fichier `content-models/droits-image.md` recensera l'état des accords par projet (à mettre en place en Phase 4).
